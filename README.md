# Portfolio — Ethan Diaï

Site statique en HTML, CSS et JavaScript. Ouvrir `index.html` dans un navigateur ou publier le contenu du dossier sur un hébergement statique tel que GitHub Pages.

## Pages
- `index.html` : accueil
- `projets.html` : galerie de projets avec filtres
- `experiences.html` : expérience professionnelle AMFREE (présentation générique)
- `profil.html` : parcours et CV
- `contact.html` : e-mail et LinkedIn

Les fiches projets se trouvent dans `projets/`. Les documents publics sont dans `assets/documents/`. Le rapport et le poster AMFREE ne sont volontairement pas inclus.

## Note CAO TN20
Les fichiers natifs CATIA sont regroupés dans `assets/documents/TN20-fichiers-CAO.zip`. Le ZIP contient les fichiers transmis, notamment les pièces et l’assemblage `assemblage_final.CATProduct`. Vérifier les références de liens entre pièces à l’ouverture dans CATIA.
